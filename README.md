# Overpass — Landing

Landing page do **Overpass**, plataforma de evolução criativa da Overlens.

Stack: Vite + React + TypeScript + Tailwind 4.

## Rodar

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Gera `dist/` autocontido — pode abrir `dist/index.html` direto no navegador.
